# Hotel Retreat — «Название текст»

Настольный многостраничный прототип гостиничного сайта и исследование систем бронирования для 30 номеров и 10 домиков в Москве.

- **Сайт:** https://hotel.168-231-101-178.sslip.io/
- **[Исследование, тарифы, расчёты и Mermaid-диаграммы](RESEARCH.md)**
- [Диаграммы отдельными файлами](docs/diagrams/)
- [Фотографии и источники](CREDITS.md)

## Статус

18 основных страниц. Выбор дат и гостей, демонстрационные результаты поиска, фильтры, фотографии и примерные тарифы. Остальные разделы — отдельные страницы-заглушки. Реальные брони и оплата не подключены, мобильная версия намеренно не разработана. Все цены и условия демонстрационные.

## Локальный просмотр

Открыть `index.html` в браузере либо выполнить `npm run preview` и открыть http://127.0.0.1:4173 . Зависимостей нет, `npm install` не требуется.

## Сборка и публикация

`npm run build` складывает только публичные файлы сайта в `dist/`.

Подготовлен workflow `IDyushin/server-kit/.github/workflows/static-site.yml` с именем сайта `hotel`: он собирает статику, загружает её в отдельную staging-папку и вызывает `site-publish`. Для автоматической публикации нужны GitHub Secrets `DEPLOY_HOST`, `DEPLOY_KNOWN_HOSTS`, `DEPLOY_SSH_KEY`; их добавление ожидает отдельного разрешения владельца. Доступов в исходниках нет. Первая публикация выполняется вручную через существующее SSH-подключение.

## Перед реальным запуском

Реальные контакты, фотографии, цены и документы; мобильная версия; выбранная PMS и её модуль/API; тестирование бронирования, оплаты, фискализации, отмен и возвратов.
